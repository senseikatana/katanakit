# katanakit

## 🚀 Descripción

Proyecto **katanakit**.

## 📦 Instalación

```bash
# Con Bun
bun install

# Con npm
npm install
```

## 🛠️ Desarrollo

```bash
# Iniciar en modo desarrollo
bun run dev

# Build para producción
bun run build

# Ejecutar tests
bun run test
```
