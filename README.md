# KatanaKit

Suite de paquetes npm para desarrollo web moderno. Cada paquete es independiente, publicado en npm.

## Paquetes

| Paquetes | npm | Descripción |
|---|---|---|
| [`js/`](katanakit-js/) | [katanakit-js](https://www.npmjs.com/package/katanakit-js) | Service toolkit TypeScript con arquitectura hexagonal |
| [`css/`](katanakit-css/) | [katanakit-css](https://www.npmjs.com/package/katanakit-css) | Mini-framework SCSS modular: design tokens, utilidades, mixins |
| [`sysli/`](katanakit-sysli/) | [katanakit-sysli](https://www.npmjs.com/package/katanakit-sysli) | Sistema de logging |

## Instalación

```bash
npm install katanakit-js
npm install katanakit-css
npm install katanakit-sysli
```

## Estructura

```
katanakit/
├── katanakit-js/      # TypeScript toolkit (hexagonal architecture)
├── katanakit-css/     # SCSS mini-framework
├── katanakit-sysli/   # Logging system
└── README.md
```
