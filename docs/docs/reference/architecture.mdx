# Architecture

## Module structure

```
src/scss/
├── main.scss          # Entry: reset + tokens + all utilities
├── _reset.scss        # Preflight (Tailwind-style)
├── _variables.scss    # Design tokens + color palettes
├── _functions.scss    # Pure functions (unit, color, fluid)
├── _mixins.scss       # Breakpoints, grid, flex, @apply, generators
├── _utilities.scss    # Utility maps + class generators
├── demo.scss          # Demo entry (main + components)
└── components/
    └── _index.scss    # Example components with @apply
```

## Design philosophy

1. **Map-driven** — all values come from `!default` maps that consumers can override
2. **Opt-in generation** — utility classes are generated by explicit mixins, not magic
3. **Zero runtime** — pure SCSS compilation, no JavaScript
4. **Composable** — import what you need, leave what you don't

## Build pipeline

```bash
# CSS artifact (npm)
npx sass src/scss/main.scss dist/css/katanakit.css --no-source-map --style=compressed

# Demo (Vite HMR)
yarn dev
```
