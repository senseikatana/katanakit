# Padding

| Class | Properties |
|---|---|
| `.p-0` | `padding: 0` |
| `.p-05` | `padding: 0.125rem` |
| `.p-base` | `padding: 1px` |
| `.p-1` | `padding: 0.25rem` |
| `.p-1-5` | `padding: 0.375rem` |
| `.p-2` | `padding: 0.5rem` |
| `.p-4` | `padding: 1rem` |
| `.p-8` | `padding: 2rem` |
| `.p-16` | `padding: 4rem` |
| `.p-96` | `padding: 24rem` |

**Directional:** `.px-*`, `.py-*`, `.pt-*`, `.pr-*`, `.pb-*`, `.pl-*`

```html
<div class="p-8">All sides</div>
<div class="px-4 py-2">Horizontal + vertical</div>
<div class="pt-8 pr-4 pb-2 pl-6">Individual sides</div>
```
