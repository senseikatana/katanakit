# Gap

| Class | Properties |
|---|---|
| `.gap-0` | `gap: 0` |
| `.gap-1` | `gap: 0.25rem` |
| `.gap-4` | `gap: 1rem` |
| `.gap-8` | `gap: 2rem` |

**Directional:** `.gap-x-*`, `.gap-y-*`

```html
<div class="flex gap-4">
  <span>Item 1</span>
  <span>Item 2</span>
</div>
```
